# Security Policy

## Supported versions

restream is under active development. Security fixes are applied to the
latest release and backported to the most recent release line on a
best-effort basis. We recommend always running the newest release.

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |
| < latest | :warning: best-effort only |

## Reporting a vulnerability

Please do **not** open a public issue for security vulnerabilities. Report
them privately through one of the following channels:

- **GitHub private security advisory**: use the "Report a vulnerability"
  button on the [security advisories](https://github.com/wings1848/restream/security/advisories)
  page of the repository.
- **Email**: `butterflywings1848@outlook.com`

Please include as much of the following as possible:

- The affected restream version(s).
- A description of the vulnerability and its impact.
- Steps to reproduce, or a proof-of-concept.
- Any relevant logs or sanitized configuration.

## Response expectation

We aim to acknowledge vulnerability reports within **3 business days** and to
send an initial assessment (confirmed / not reproducible / out of scope)
within **7 business days**. We will coordinate disclosure with you and credit
you for the report unless you prefer to remain anonymous.
